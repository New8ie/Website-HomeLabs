# Memulai HomeLab dengan Proxmox

HomeLab adalah lingkungan server pribadi yang digunakan untuk belajar, eksperimen, dan menguji teknologi baru. Pada panduan ini, kita akan menggunakan **Proxmox VE** sebagai platform virtualisasi.

## Peralatan yang Dibutuhkan
- Server atau PC bekas
- Minimal RAM 8GB
- Storage SSD/HDD
- Koneksi internet stabil

## Langkah Instalasi
1. Download ISO Proxmox dari situs resmi.
2. Boot server menggunakan USB installer.
3. Ikuti wizard instalasi hingga selesai.

---

Dengan Proxmox, kamu bisa mengatur VM, container, dan backup secara fleksibel di HomeLab kamu.
